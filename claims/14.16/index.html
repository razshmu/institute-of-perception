14.16 Constructed-time toy simulation

Claim

In a toy simulation whose data are generated by a τ-rescaling model, a Level-1 constructed-time model recovers the rescaling in leave-one-context-out validation.

Ten contexts had true τ = exp(a0 + a1·z). The constructed-time model gained about 116.5 nats in held-out log-likelihood over a time-only model. Between-context threshold variance fell by about 97%. This is a parameter-recovery demonstration of the fitting pipeline.

What is new

A worked demonstration of the pipeline; it adds no evidence for the hypothesis.

Prior art

Standard parameter-recovery simulation practice; Wang et al. 2018.

Test and evidence

One simulation run without released code.

Counts against

None: the gain follows from the simulation design, so the run cannot refute the claim.

An outcome that weakens or narrows the claim without contradicting it.
